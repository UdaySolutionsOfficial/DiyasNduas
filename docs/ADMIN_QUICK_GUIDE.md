# Admin Quick Reference Guide

## Daily Store Checklist

1. **Check Dashboard**: View pending orders, today's order count, sales value, and low-stock alerts.
2. **Handle New Order Alerts**:
   - Popup alert appears $\rightarrow$ Click **View Details**.
   - Verify item stock and delivery address.
   - Click **Confirm & Message Customer** to send WhatsApp confirmation.
   - Click **Print Receipt** for transport packaging.
3. **Update Product Stock**:
   - Go to **Products** $\rightarrow$ Click **Edit** $\rightarrow$ Update **Stock Quantity** $\rightarrow$ Click **Save**.
4. **End of Day**:
   - Ensure all fulfilled orders are marked **Delivered / Fulfilled**.
   - Click **Logout** if using a shared or shop computer.
