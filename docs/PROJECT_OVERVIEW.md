# Crackers King — Project Overview

## Objective
Crackers King is a mobile-first, partial e-commerce web application for a crackers business. Customers can browse products, search, view detailed product information with dynamic discount calculations, add items to cart/wishlist, and submit order requests without creating an account or paying online.

## Standalone Project Guarantee
Crackers King is a 100% independent application built completely from scratch. It shares zero code, configuration, Firebase credentials, or assets with any previous project.

## Completed Phase Progress
- **Phase 0**: Project Foundation, Technical Setup & Safe Firebase Architecture
- **Phase 1**: Premium Design System, Design Tokens & Application Shells
- **Phase 2**: Customer Home, Banner Carousel, Category Filtering, Product Search, Mobile-First Product Cards, Dynamic Discount Calculation, and Product Details Experience
